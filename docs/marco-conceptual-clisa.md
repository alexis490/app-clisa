- Inventario: Conjunto de bienes o productos que una empresa mantiene disponibles para su uso o venta y que registra y controla para gestionar sus existencias ([Heizer et al., 2017](https://www.pearson.com/en-gb/subject-catalog/p/Heizer-Operations-Management-Sustainability-and-Supply-Chain-Management-Global-Edition-12th-Edition/P200000008819)).
- Producto: Bien tangible destinado a la venta o al uso de una empresa, cuyas entradas y salidas se registran para mantener actualizado el stock ([Heizer et al., 2017](https://www.pearson.com/en-gb/subject-catalog/p/Heizer-Operations-Management-Sustainability-and-Supply-Chain-Management-Global-Edition-12th-Edition/P200000008819)).
- SKU: Código interno que identifica un producto o una variante para distinguirlo de otros artículos y controlar sus existencias ([Shopify, s. f.](https://help.shopify.com/en/manual/products/details/sku)).
- Stock o existencias disponibles: Cantidad disponible de un producto en un momento determinado ([Heizer et al., 2017](https://www.pearson.com/en-gb/subject-catalog/p/Heizer-Operations-Management-Sustainability-and-Supply-Chain-Management-Global-Edition-12th-Edition/P200000008819)).
- Número de serie y lote: El número de serie identifica una unidad individual, mientras que el número de lote identifica un conjunto de unidades que comparten un origen o una condición de producción ([GS1, 2017](https://ref.gs1.org/standards/global-traceability/2.0.0/)).
- Movimiento de inventario: Operación que cambia la cantidad o la ubicación de las existencias ([Microsoft, s. f.-b](https://learn.microsoft.com/en-us/dynamics365/supply-chain/inventory/inventory-journals)).
- Salida de productos: Movimiento de inventario que reduce las existencias disponibles en el lugar de origen debido a una venta, un traslado o una entrega. Su registro permite mantener actualizado el stock ([Microsoft, s. f.-b](https://learn.microsoft.com/en-us/dynamics365/supply-chain/inventory/inventory-journals)).
- Traspaso: Movimiento de productos entre ubicaciones ([Microsoft, s. f.-b](https://learn.microsoft.com/en-us/dynamics365/supply-chain/inventory/inventory-journals)).
- Registro de información e historial de movimientos: Captura y conservación de los datos de una operación para poder consultarlos después ([Microsoft, s. f.-b](https://learn.microsoft.com/en-us/dynamics365/supply-chain/inventory/inventory-journals)).
- Trazabilidad: Capacidad de seguir la historia o el movimiento de un producto mediante identificadores y registros vinculados ([GS1, 2017](https://ref.gs1.org/standards/global-traceability/2.0.0/)).
- Código de barras: Representación legible por un escáner que codifica datos como el identificador de un producto ([GS1, 2017](https://ref.gs1.org/standards/global-traceability/2.0.0/)).
- Escaneo de códigos: Captura e interpretación de la información codificada en un código de barras u otro código visual mediante una cámara o un lector ([Google for Developers, s. f.](https://developers.google.com/ml-kit/vision/barcode-scanning/code-scanner)).
- Google Code Scanner: Servicio de Google Play para Android que permite leer códigos de barras mediante la cámara y devolver el contenido del código a la aplicación ([Google for Developers, s. f.](https://developers.google.com/ml-kit/vision/barcode-scanning/code-scanner)).
- Reporte de movimientos: Presentación organizada de los registros para revisar la actividad del inventario ([Microsoft, s. f.-c](https://learn.microsoft.com/en-us/dynamics365/supply-chain/cost-management/inventory-value-report-storage)).
- Importación de inventario: Incorporación de datos de productos y existencias desde una fuente externa, como una hoja de cálculo, a un sistema de inventario ([Microsoft Support, s. f.-b](https://support.microsoft.com/en-us/excel/get-started/import-or-export-text-txt-or-csv-files)).
- XLSX: Formato de archivo de los libros de cálculo de Excel basado en Office Open XML, que permite guardar hojas, celdas y fórmulas ([Microsoft Support, s. f.-a](https://support.microsoft.com/en-us/excel/file-formats-that-are-supported-in-excel)).
- CSV: Formato de texto para datos tabulares que separa los registros con saltos de línea y los campos de cada registro con comas ([Shafranovich, 2005](https://www.rfc-editor.org/info/rfc4180/)).
- Exportación de datos: Proceso de extraer información de un sistema y guardarla en un formato que permite consultarla o reutilizarla fuera de él ([Microsoft, s. f.-f](https://learn.microsoft.com/en-us/power-apps/maker/data-platform/data-platform-import-export)).
- Mapeo de columnas: Asignación de las columnas de un archivo de origen a los campos que espera el sistema, como código, nombre y cantidad ([Microsoft, s. f.-d](https://learn.microsoft.com/en-us/azure/data-factory/copy-activity-schema-and-type-mapping)).
- Validación de datos: Comprobación de que los datos cumplen las reglas requeridas para el uso previsto ([Government Data Quality Hub, 2020](https://www.gov.uk/government/publications/the-government-data-quality-framework/the-government-data-quality-framework)).
- Incidencia de importación: Problema detectado durante el análisis del archivo que requiere revisión, por ejemplo, un código duplicado o una cantidad inválida ([Microsoft, s. f.-a](https://learn.microsoft.com/en-us/azure/data-factory/copy-activity-fault-tolerance)).
- Comparación de inventario: Revisión de las cantidades registradas en dos fuentes de inventario para identificar diferencias en las existencias ([Microsoft, s. f.-b](https://learn.microsoft.com/en-us/dynamics365/supply-chain/inventory/inventory-journals)).
- Vista previa de importación: Presentación de los datos de origen o de los cambios propuestos para revisarlos antes de confirmar una importación ([Microsoft Support, s. f.-c](https://support.microsoft.com/en-us/excel/import-data-from-data-sources-power-query)).
- Sincronización de inventario: Actualización de los registros de existencias para reflejar los cambios de una fuente de inventario en otra ([Microsoft, s. f.-e](https://learn.microsoft.com/en-us/dynamics365/supply-chain/inventory/inventory-visibility-sync-changes)).
- Historial de importaciones: Registro de las ejecuciones de importación y de sus resultados, que permite consultar cuándo ocurrieron y cuál fue su estado ([Microsoft, s. f.-g](https://learn.microsoft.com/en-us/azure/data-factory/monitor-visually)).
- Clasificación de productos: Organización de productos en grupos según características comunes, como su tipo, función o uso ([GS1, 2026](https://ref.gs1.org/standards/gpc/2026-05/)).
- Gemini: Familia de modelos de inteligencia artificial generativa de Google capaces de interpretar instrucciones y producir respuestas a partir de los datos que reciben ([Google AI Studio, s. f.](https://aistudio.google.com/docs)).
- Aplicación móvil: Software diseñado para ejecutarse en dispositivos móviles ([Android Developers, s. f.-b](https://developer.android.com/guide/components/fundamentals)).
- Android: Sistema operativo para dispositivos móviles que proporciona la plataforma de ejecución de las aplicaciones Android ([Android Developers, s. f.-b](https://developer.android.com/guide/components/fundamentals)).
- Interfaz de usuario (UI): Conjunto de elementos con los que interactúa la persona usuaria, como pantallas, botones, formularios y listas ([Android Developers, s. f.-e](https://developer.android.com/compose)).
- Experiencia de usuario (UX): Conjunto de percepciones y respuestas que resultan de utilizar un producto ([Norman y Nielsen, s. f.](https://www.nngroup.com/articles/definition-user-experience/)).

- Jetpack Compose: Conjunto de herramientas de Android para construir interfaces declarativas en Kotlin ([Android Developers, s. f.-e](https://developer.android.com/compose)).
- Material Design 3: Sistema de diseño que proporciona componentes y pautas de color, tipografía y forma para construir interfaces coherentes ([Android Developers, s. f.-h](https://developer.android.com/develop/ui/compose/designsystems/material3)).
- ViewModel: Componente de arquitectura de Android que administra el estado de una pantalla y lo conserva durante cambios de configuración, como la rotación del dispositivo ([Android Developers, s. f.-i](https://developer.android.com/topic/libraries/architecture/viewmodel)).
- Kotlin: Lenguaje de programación de tipado estático que se puede usar para desarrollar aplicaciones Android ([JetBrains, s. f.](https://kotlinlang.org/docs/android-overview.html)).
- Activity y ciclo de vida: Una *Activity* es un componente Android que aloja una interfaz. Su ciclo de vida comprende las transiciones que ocurren al iniciarse, mostrarse, pasar a segundo plano o destruirse ([Android Developers, s. f.-b](https://developer.android.com/guide/components/fundamentals); [Android Developers, s. f.-g](https://developer.android.com/guide/components/activities/activity-lifecycle)).
- XML: Lenguaje de marcado que permite estructurar datos mediante etiquetas. En Android se utiliza, entre otros fines, para declarar recursos como cadenas, colores y estilos ([Android Developers, s. f.-a](https://developer.android.com/guide/topics/resources/providing-resources); [World Wide Web Consortium, 2008](https://www.w3.org/TR/xml/)).
- Mockup: Representación visual detallada de una pantalla que sirve de referencia para implementar su diseño ([Figma, s. f.](https://www.figma.com/designers/)).
- Figma: Herramienta colaborativa para diseñar interfaces y elaborar prototipos que permiten simular interacciones y recorridos entre pantallas ([Figma, s. f.](https://www.figma.com/designers/)).
- Firebase: Plataforma de Google para desarrollar aplicaciones móviles y web que ofrece servicios de autenticación, bases de datos y alojamiento ([Google, s. f.-c](https://firebase.google.com/)).
